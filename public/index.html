🧭 처음이세요? 이렇게 쓰시면 돼요
  1. 입력 템플릿 받기
    녹색 칸에 값을 채워요 (또는 화면에 바로 입력)
  2. HWPX 업로드
    Ct와 기재값이 자동으로 들어와요
  3. 필수 항목 확인
    Slope · Y-inter · R² · 효율 · 회수율이 자동 계산돼요
  4. 미리보기 → 내보내기
    HWPX · 인쇄 · PDF로 저장해요

필수 계산에 꼭 필요한 값이에요. 비어 있으면 점선 테두리로 표시되고 내보내기가 잠시 막혀요.
선택 비워도 괜찮아요. 넣으면 결과서 기재값과 일치 여부를 비교해 드리거나 서식 상단에 기록해요.

1

결과서 불러오기

이미 작성한 결과서(.hwpx)를 올리면 값이 자동으로 채워져요.
⬇️ 입력 템플릿 받기 또는 이 영역에 파일을 끌어다 놓으세요. 파일은 브라우저 안에서만 처리돼요.

처음이라면 템플릿을 받아 녹색 칸(Ct, 기재값 등)에 입력한 뒤 다시 올리세요. 이 앱의 녹색 입력칸과 같은 구조예요.

2

기관 정보 선택

결과서 상단에 기록돼요. 모두 비워도 괜찮아요.

아래 회색 기울임 글씨는 재미로 넣어 둔 가안(가상 예시)이에요. 칸을 클릭하면 지워지니 본인 기관 정보를 입력해 주세요.

3

표준곡선 Ct 입력 필수

희석 5단계 × 3반복의 Ct 값을 넣어요. 최소 2단계부터 계산할 수 있어요.

희석농도 (copies/µL)반복 1반복 2반복 3

칸을 클릭해 입력하고 ↑ ↓ ← → / Enter로 옮겨 다녀요. 엑셀에서 복사한 여러 칸을 붙여넣기할 수도 있고, 가로로 복사했다면 위의 행↔열 바꾸기를 켜 보세요.

엑셀처럼 쓰는 스프레드시트예요: 방향키/Enter/Tab 이동 · 여러 칸 복사·붙여넣기 · 선택 영역 모서리 드래그로 채우기. 간편 입력과 값이 항상 같이 움직여요.

노란 칸 = 비어 있음 · 빨간 칸 = 숫자가 아님

4

표준곡선 결과

증폭효율(Efficiency)은 가장 중요한 지표예요. 기준 범위 안인지 한눈에 보여 드려요.

결과서 기재값 vs 계산값 선택

결과서에 적힌 Slope · Y-inter · R²를 넣으면 계산값과 비교해 일치/불일치를 알려 드려요. 비교하지 않을 거면 비워도 돼요.

결과서 기재값계산값차이판정
Slopem = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)²
Y-interb = ȳ − m·x̄
R²[Σ(x−x̄)(y−ȳ)]² / [Σ(x−x̄)²·Σ(y−ȳ)²]

표준곡선: Ct = m·x + b (x = log10 농도 또는 희석단계, 전 반복 Ct를 최소제곱 회귀) · 증폭효율 E = 10(−1/m) − 1

5

회수율 분석 필수

Ct와 spiked 농도를 넣으면 측정값(copies/mL)과 회수율(%)을 계산해요.

측정값 = 10^((Ct − Y-inter) / Slope) · 회수율(%) = 측정값 / spiked × 100

계산값기재값 선택판정

6

결과서 내보내기

표준서식에 기관 정보와 계산값을 채워 HWPX로 만들어요. 결과서를 올렸다면 그 파일을 서식으로 써서 그림 등이 그대로 유지돼요.

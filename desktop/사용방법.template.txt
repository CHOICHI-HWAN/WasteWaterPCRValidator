[실행]
1) WasteWaterPCRValidator-win-x64.exe 를 더블클릭합니다. (설치 불필요 · 인터넷 불필요 · 약 2.8MB)
2) 잠시 후 기본 브라우저에 앱이 자동으로 열립니다. (별도의 창은 뜨지 않습니다)
   - 열리지 않으면 브라우저 주소창에  http://127.0.0.1:47321/  를 입력하세요.
3) 사용이 끝나면 브라우저 탭을 닫으세요. 몇 초 후 프로그램도 자동으로 종료됩니다.
   - 실행 중에 exe를 다시 더블클릭하면 새로 띄우지 않고 같은 화면을 다시 엽니다.
   - 강제로 끄려면 작업 관리자에서 WasteWaterPCRValidator-win-x64.exe 를 종료하세요.

[처음 실행할 때 Windows 경고가 뜨는 경우]
- "Windows의 PC 보호"(SmartScreen) 창이 뜨면: [추가 정보] → [실행] 을 누르세요.
  코드 서명(유료 인증서)이 없는 프로그램이라 나타나는 경고입니다.
- 백신 프로그램이 처음 한 번 검사하느라 실행이 늦거나 차단하면, 아래 SHA-256 값으로 파일이 맞는지 확인한 뒤 허용하세요.
- 기관 보안 정책으로 exe 실행이 막혀 있으면 웹 버전(https://wwpcr.web.app)을 사용하세요.

[보안]
- 입력한 값과 업로드한 HWPX 파일은 이 PC 밖으로 전송되지 않습니다. 외부 접속(통계 포함)도 하지 않습니다.
- 이 PC에서만 접속되는 주소(127.0.0.1)로 동작하며, 다른 PC에서는 접속할 수 없습니다. 브라우저 보안 정책으로 외부 주소 접속도 차단됩니다.
- 입력한 값은 저장되지 않습니다. (판정 기준 등 설정만 이 PC의 브라우저에 저장)

[요구 사항] Windows 10 / 11 (64비트), 최신 Chrome · Edge · Whale 등 브라우저
[참고] 다른 프로그램이 포트(47321)를 쓰고 있으면 자동으로 다음 번호를 사용합니다. 주소 끝 번호가 달라지면 저장된 설정(허용오차 등)은 처음 값으로 보일 수 있습니다.
